## Summary

**Core confirmed feature set (High confidence):**
- Multi-currency accounts (USD, EUR, GBP)
- Individual + Business onboarding with KYC
- Debit card (virtual + physical) with controls
- International transfers (SWIFT/SEPA)
- Mobile app (iOS + Android) with biometric auth
- Real-time push notifications
- AML/KYC compliance

**Hypothesized / unconfirmed:**
- Team/multi-user access for business accounts
- API access for business customers
- Payment scheduling
- Invoice/expense integration
